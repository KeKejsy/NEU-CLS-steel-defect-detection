**两条铁律**
1. **不要 `pip install paddledet`** —— 它要求 `numpy<2`，装上会把 numpy 降级，A 的数据脚本与 B/C 的代码会一起崩（详见 README 第二节）。
2. **所有脚本都在项目根目录用 `python src/xxx/yyy.py` 运行**，不要 `import src.xxx`；C 的脚本在开头做了 `sys.path.insert(0, 脚本目录)`。

## 3. 一键运行整个项目（推荐）

```bash
python run_project.py --profile eval        # 只自检/汇总/校验，不训练（约 5 秒）
python run_project.py --profile standard    # 训练最终检测方案并评估 val+test（GPU 约 1 小时）
python run_project.py --profile full        # 再加单阶段 YOLOv3 / PP-YOLOE-s（GPU 约 3 小时）
python run_project.py --quick               # 冒烟：每步都跑但极小规模（约 5 分钟）
python run_project.py --dry-run             # 只打印将执行的命令，不写任何文件
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--device auto\|cpu\|gpu` | 默认自动探测；`cpu` 会自动降级为 96 输入 + 小 epoch（CPU 上跑 40 epoch 要一夜） |
| `--only a,b` / `--skip a,b` | 只跑/跳过指定阶段（阶段名见 `--list`） |
| `--resume` | 跳过已完成的阶段（默认是重跑，不需要它） |
| `--retrain` / `--force` | 权重已存在也重新训练（默认复用，避免白跑几小时） |
| `--in-size` / `--epochs-scale` | 调输入尺寸 / 训练规模 |
| `--no-pretrained` | 复现旧流水线口径（随机初始化主干） |

要点：
- **解释器自动识别**：没激活 conda 环境时直接 `python run_project.py`（系统 Python 通常没装 paddle），
  脚本会自动找到机器上装了 paddle 的解释器（本项目是 `miniconda3\envs\paddle_env\python.exe`）
  并用它重新运行自己；不想要这个行为就加 `--no-auto-python`，或用 `--python <解释器路径>` 手动指定。
- **重跑策略**：**默认重跑每个阶段**（上次的完成记录只会提示一句，不会跳过）；
  想利用断点续跑、跳过已完成的阶段，加 `--resume`。训练阶段默认**复用已有权重**，
  想强制重训加 `--retrain`（或 `--force`，等价）。
- **训练与评估的 `--norm/--in-size` 由同一份配置生成**，不会配错（这是最容易静默掉点的地方）。
- 运行报告：`results/metrics/run_project_summary.json`；各阶段日志在 `results/logs/run_project/`。

## 4. 手动分步运行（想单独跑某一步）

### A · 数据（成员 A）
```bash
python src/data/check_submit.py          # 完整性自检（23 项）
# 从零重建：fetch_dataset.py → download_check.py → split_dataset.py → xml2voc.py → eda.py
```

### B · 分类（成员 B，CPU 即可）
```bash
python src/cls/train.py --model mobilenet_v3_small   # 约 26 分钟（CPU）
python src/cls/train.py --model resnet50_vd          # 约 116 分钟（CPU）
python src/cls/eval_cls.py --model resnet50_vd
python src/cls/cam.py --model resnet50_vd            # 类激活图
python src/cls/export.py --model resnet50_vd         # 导出推理模型
python src/cls/train_curves.py                       # 训练曲线
```

### C · 检测（成员 C，最终方案，需 GPU）
```bash
# ① 训练验证器（约 3 分钟）
python src/det/train_verifier.py --name verifier_pre128 --pretrained --norm imagenet --in-size 128

# ② 训练精修器，主干从①迁移（约 18 分钟）
python src/det/train_refiner.py --name refiner_giou128 --pretrained --norm imagenet \
    --in-size 128 --reg-loss giou --init-verifier results/weights/verifier_pre128_best.pdparams

# ③ 正式评估（val / test 各约 22 分钟；--norm 与 --in-size 必须与训练一致）
python src/det/eval_fused.py --split test --mode fuse \
    --stride 12 --score-th 0.6 --nms-iou 0.4 --top-k 150 --max-det 50 \
    --norm imagenet --in-size 128 \
    --verifier-weights results/weights/verifier_pre128_best.pdparams \
    --refiner-weights  results/weights/refiner_giou128_best.pdparams \
    --tag test_fuse_pre128

# ④ 真值-预测对比图（分层抽样）
python src/det/tools/viz_fused.py --split val --per-class 2 --norm imagenet --in-size 128

# 单阶段失败基线（可选，很慢）
python src/det/train.py --config src/det/configs/yolov3.yml      # 120 epoch ≈ 40 分钟
python src/det/train.py --config src/det/configs/ppyoloe_s.yml   # 100 epoch ≈ 86 分钟
python src/det/eval_det.py --model yolov3 --split test

# 旧流水线口径 = 把上面所有 --norm imagenet --in-size 128 换成 --norm none --in-size 96，
# 权重换成 verifier_best / refiner_best
```

### D · 工具链（成员 D）
```bash
python src/tools/run_all.py        # 数据自检 → results/summary_table.csv → summary_compare.png
# 或分别跑 src/tools/log2table.py、src/tools/plot_summary.py
```

## 6. 权重怎么来（重要）

权重按 `.gitignore` 设计**不进仓库**，GitHub 上一个 `.pdparams` 都没有。三种获取方式：

1. **用打包好的分发包**（推荐）：解压后权重、数据、代码都在，直接 `python run_project.py --profile eval`
2. **自己训**：`--profile standard` 会把两个区域判别模型训出来（GPU 约 22 分钟）
3. **只复现最终指标**只需两个权重：`verifier_pre128_best` + `refiner_giou128_best`（19.8 MB）

## 7. 常见问题（FAQ）

| 现象 | 原因 / 处理 |
|---|---|
| `No module named paddle` / 版本不对 | 说明当前的 `python` 不是项目环境（本机实测：系统 Python 3.14 没装 paddle）。`run_project.py` 会自动切换到带 paddle 的解释器；若是单独跑 `src/xxx.py`，请先 `conda activate paddle_env`，或直接用 `miniconda3\envs\paddle_env\python.exe` |
| `No module named core` / `src.det` | 没在项目根目录运行；必须 `python src/det/xxx.py` |
| 指标比文档低很多 | `--norm` 或 `--in-size` 与训练时不一致（预训练特征被错位的输入分布稀释，**不报错**） |
| 训练异常慢（几十倍） | ① 有两个训练进程并发（显存重试，实测慢 134 倍）② PP-YOLOE-s @640 的 batch>8（顶满 12 GB） |
| 路径报错/找不到文件 | 项目路径必须**纯英文、无空格**（项目铁律） |
| 首次跑 `--pretrained` 卡住 | 在下载 ImageNet 权重到 `~/.cache/paddle/hapi/weights/`，约 10 MB；离线环境可加 `--no-pretrained` |
| 文档校验说缺数字 | `python src/det/tools/check_docs.py` 会列出缺哪几项，去对应文档补上（只接受小数点后 ≥3 位的写法） |
| 想重复用测试集 | 按项目铁律需团队确认（本项目测试集已用过两次：首轮交付与优化轮） |
